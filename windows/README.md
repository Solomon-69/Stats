Stats for Windows
=================

How your PC is doing, in plain words. Lives in the system tray (click the small bars icon, bottom right).

Run Stats.exe. No install needed. Windows may show a blue "protected your PC" screen the first time because the app is not signed:
click "More info", then "Run anyway".

Based on exelban/stats (MIT licence). https://github.com/Solomon-69/Stats
